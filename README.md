DRESSLOOP
DressLoop is a web-based application developed to address the issue of unused or reusable  items not reaching the people who need them. The system connects donors with receivers through a structured and transparent process.

Features
1)User authentication for Donor and Receiver
2)Creation of donation listings (clothes and other reusable items)
3)Viewing available items
4)Approval and rejection of requests
5)Contact sharing after approval

Tech Stack
Frontend: React, HTML, CSS
Backend: Node.js, Express.js
Database: Firebase / PostgreSQL

Screenshots


How to Run
1.Clone the repository
2.Install dependencies using npm install
3.start the application using npm start

Future Improvements
1.Implementation of chat system
2.Location-based filtering
3.Donation tracking system

Conclusion
DressLoop provides a simple and effective solution to bridge the gap between donors and receivers, ensuring better utilization of unused resources.
